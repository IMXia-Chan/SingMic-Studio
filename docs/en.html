SingMic Studio Pro Privacy Policy

Effective date: 2026-10-30 Applies to: SingMic Studio Pro 1.0 and later (including the Plug-in Host package) Developer and publisher: IMXia-Chan

This policy is written to meet Microsoft Store Policy 10.5 (Personal Information). It states, item by item: what personal information the Software accesses, collects and transmits; how that information is used, stored and secured; the types of parties to whom it is disclosed; the controls users have; and how users may access their own information.

1. Scope

SingMic Studio Pro (the “Software”) is a recording, tuning and mixing application that runs on the user's own computer and is distributed as an MSIX Desktop Bridge (Win32) package. This policy covers the main application and the companion Plug-in Host package described in section 9.

The Software does not operate any server. There is no cloud storage for user data and no account system.

2. Information the Software accesses, collects and transmits

2.1 Information the Software does not collect

  • no user accounts, no registration, and no collection of names, phone numbers, email addresses or any identity information;
  • no device identifiers, hardware information or installation identifiers;
  • no usage statistics, feature-click records or session durations;
  • no telemetry, crash reporting, advertising or third-party analytics SDK of any kind;
  • no access to contacts, messages, location, calendar or the clipboard;
  • no access to the camera.

2.2 Information accessed on the device and never transmitted

To record and mix, the Software accesses the following when the user acts. It is processed only in local memory and local files and is not sent to any server:

  • Audio captured from the microphone: accessed only when the user starts recording or enables pitch detection and beat analysis; the Software does not record continuously in the background;
  • Audio and project files the user imports or selects: chosen by the user in the system file picker; the Software does not scan files unrelated to the current project;
  • The list and names of audio input and output devices: used to select recording and playback devices;
  • The user's VST3 plug-in folders: read only when the user uses the plug-in feature.

2.3 Information that leaves the device

The Software needs no network connection by default. The features below are triggered by the user and use only services and keys configured by the user:

FeatureWhat is sentRecipient
AI backing-track generationthe style description, lyrics, duration and key entered by the userthe platform the user selects and configures with their own API key
Mixing assistant (natural-language parameter tuning)one sentence typed by the user, plus track and clip parameters in the project (gain, pan, plug-in parameters, pitch offset, etc.)the DeepSeek endpoint configured by the user

Never sent: full songs, audio from other tracks, project files, file paths, file names, project names, or any identifier relating to the device. If the user has not configured the corresponding service, these features are unavailable and the Software will not contact any server on its own.

3. How information is used

Information that leaves the device has exactly one purpose: to fulfil the single request the user has just initiated — to generate a backing track from the description and lyrics the user supplied; to adjust mix parameters from the user's sentence and parameter values; to convert the timbre of one audio segment. It is not used for anything else: not for model training, not for profiling, not for advertising, and not combined with data from other sources.

Audio and project data on the device are used only for the user's own editing, rendering and export.

4. How information is stored and how long it is kept

  • Recordings, imported audio, project files, render cache and preferences: stored in the local data directory %LOCALAPPDATA%\SingMic\data and kept until the user deletes them;
  • API keys entered by the user: stored in plain text in %USERPROFILE%\.singmic\, also kept until the user deletes them;
  • Diagnostic logs written when the program crashes: written to the local data directory only, never uploaded, deletable at any time;
  • The Software operates no servers and keeps no copy of user data on any server, so there is no server-side retention period.

Uninstalling the Software does not delete these directories, so that projects and recordings are preserved. To remove everything, delete both directories manually.

5. How information is protected

  • The Software has no server-side component, so user data never exists in a cloud and there is no server-side surface to be breached;
  • User data is stored under the current Windows user profile and protected by operating-system account permissions; please protect your system account;
  • API keys are stored in plain text in the directory above and can be read by other programs running as the same Windows user. The Software does not implement its own key vault; we recommend a sign-in password and keeping Windows up to date;
  • Transport encryption for third-party services is determined by those services (mainstream services use HTTPS). For a server address the user enters themselves, the user is responsible for its security.

6. Types of third parties to whom information is disclosed

The Software does not sell, rent or share user data. The only disclosure is the set of requests listed in section 2.3, each triggered by the user:

  • the AI platform the user selects (for backing-track generation);
  • the language-model endpoint the user configures (for the mixing assistant's parameter conversion);
  • the inference server the user sets up (for voice conversion; data stays on the device when none is configured);
  • public model download locations (a download request only, carrying no user data).

All of these are chosen and configured by the user. The Software does not proxy, relay or register accounts on the user's behalf. Those services process data under their own privacy policies and terms. If a service the user chooses is located outside their country or region, the relevant data will be transferred internationally as part of that request, initiated and decided by the user.

7. User controls

  • Network: with no API key and no server address configured, the Software has no network functionality and does not attempt to connect;
  • Per-feature control: every network feature is triggered individually in the UI; nothing connects in the background;
  • Microphone: opened only when the user starts recording or enables analysis, and can be stopped at any time;
  • Local-only option: personal voice conversion runs on the device by default when no server is configured and sends no audio;
  • Withdrawal and erasure: deleting the local data directories removes all local data; removing an API key from Settings withdraws authorisation for that service.

8. How users may access their information

All data is on the device and the user can view, copy and export it at any time:

  • recordings, projects and exports: open the data directory in File Explorer;
  • settings and API keys: view them in Settings inside the Software, or read the files under %USERPROFILE%\.singmic\;
  • because there is no server-side storage, there is no need to apply to the developer for access to or export of data.

9. Plug-in Host package

VST3 plug-in support is provided by a separate Plug-in Host package. It is installed and runs independently of the main application, as its own program.

  • it reads and writes audio and plug-in files locally only; it does not use the network and collects no information;
  • the main application does not start it unless plug-ins are loaded;
  • if the package is not installed, all other features of the main application keep working;
  • it is distributed under GPL-3.0, and its complete corresponding source code is included with the package.

10. Models and downloads

Speech recognition and AI noise reduction use models that run on the device. After the user confirms, model files are fetched from a public download location and saved to the local data directory. The download request contains only the file request itself — no user data, no recordings and no identifiers.

Distribution of and updates to the application itself are provided by the Microsoft Store. The Plug-in Host package and related documents are published in the project's public repository at github.com/IMXia-Chan/SingMic-Studio.

11. Children

The Software does not collect any information from children, and it has no account system or content-publishing features.

12. Legal compliance and changes to this policy

This policy is written in accordance with applicable law and Microsoft Store policy. When the Software adds features or changes how it handles data, this policy is updated accordingly and a new effective date is shown on this page; any change that expands the scope of data collection is called out separately in the release notes.
