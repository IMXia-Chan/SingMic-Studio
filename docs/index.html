声麦 Studio Pro 隐私政策

生效日期：2026-10-30 适用版本：声麦 Studio Pro 1.0 及以后（含插件支持包） 开发与发布：IMXia-Chan

本政策按微软商店政策 10.5「个人信息」的要求编写，逐项说明：本软件访问、收集与传输哪些信息，这些信息如何被使用、存储与保护，披露给哪类第三方，用户拥有哪些控制权，以及用户如何访问自己的信息。

一、适用范围

声麦 Studio Pro（以下简称「本软件」）是一款在用户自己的电脑上运行的录音、修音与混音软件，以 MSIX 桌面桥（Desktop Bridge / Win32）形式分发。本政策适用于主程序，以及与其配套的「插件支持包」（第九节）。

本软件不运营任何服务器，没有供用户上传数据的云端空间，也没有账号体系。

二、本软件访问、收集与传输的信息

2.1 本软件不收集的信息

  • 不设立用户账号，不要求注册，不收集姓名、手机号、电子邮箱或任何身份信息；
  • 不收集设备标识符、硬件信息或安装标识；
  • 不收集使用统计、功能点击记录、会话时长等行为数据；
  • 不内置任何遥测、崩溃上报、广告或第三方分析 SDK；
  • 不读取通讯录、短信、位置、日历或剪贴板；
  • 不访问摄像头。

2.2 在本机访问、但不外发的信息

为完成录音与混音，本软件在用户操作时访问下列信息。这些信息只在本机内存与本地文件中处理，不发送到任何服务器：

  • 麦克风采集的音频：仅在用户点击录音、或启用音高检测与节拍分析时访问，不在后台持续录音；
  • 用户主动导入或选择的音频与工程文件：由用户在系统中自行选取，本软件不扫描与本工程无关的文件；
  • 音频输入输出设备的列表与名称：用于选择录音与播放设备；
  • 用户安装的 VST3 插件目录：仅在用户使用插件功能时读取。

2.3 会离开本机的信息

本软件默认不需要联网。下表列出的功能由用户主动触发，且只使用用户自己配置的服务与密钥：

功能发送的内容接收方
AI 伴奏生成用户输入的风格描述、歌词、时长与调式用户在设置中选择并配置 API Key 的服务平台
调音助手（自然语言调参）用户输入的一句话，以及工程中轨道与音频块的参数（增益、声像、插件参数、音高偏移等）用户自行配置的 DeepSeek 接口
个人音色补音用户选中的那一段音频（不超过 15 秒）用户自行搭建的推理服务器（未配置时在本机运行，不发送）
模型文件下载无（仅发起下载请求）公开的下载地址（见第十节）

明确不发送：完整歌曲、其他音轨的音频、工程文件、文件路径、文件名、工程名，以及任何与本机相关的标识信息。用户未配置相应服务时，上述功能不可用，本软件不会自行连接任何服务器。

三、信息如何被使用

离开本机的信息只有一种用途：完成用户刚才主动发起的那一次请求——用用户提供的描述与歌词生成伴奏；用用户的一句话与参数建议调整混音参数；用一段音频做音色转换。此外不做任何用途：不用于训练模型、不做用户画像、不做广告定向、不与其他来源的数据合并。

本机内的音频与工程数据，只用于用户自己的编辑、渲染与导出。

四、信息如何被存储与保存期限

  • 录音、导入音频、工程文件、渲染缓存、偏好设置：保存在本机数据目录 %LOCALAPPDATA%\SingMic\data，保留至用户自行删除；
  • 用户填写的 API Key：以明文保存在 %USERPROFILE%\.singmic\ 目录，同样保留至用户删除；
  • 程序崩溃时的诊断日志：仅写入本机数据目录，不上传，用户可随时删除；
  • 本软件不运营服务器，不在任何服务器上保留用户数据的副本，因此不存在服务端的保存期限。

卸载本软件不会自动删除上述目录（以保留用户的工程与录音）；如需彻底清除，请手动删除这两个目录。

五、信息如何被保护

  • 本软件不含服务器端组件，用户数据不存在于云端，因而不存在服务端数据泄露的风险面；
  • 用户数据存放在当前 Windows 用户目录下，受操作系统账户权限保护，请妥善保管系统账户；
  • API Key 以明文形式保存在上述目录，可被以同一 Windows 用户身份运行的其他程序读取；本软件不自建密钥库，建议为本机设置登录密码并保持系统更新；
  • 与第三方服务通信时的传输加密由该服务决定（主流服务均使用 HTTPS）；用户自行填写的服务器地址，其安全性由用户自己负责。

六、信息被披露给哪类第三方

本软件不出售、不出租、不共享用户数据。唯一的对外披露，是 2.3 所列、由用户主动触发的那几类请求：

  • 用户自行选择的 AI 服务平台（用于伴奏生成）；
  • 用户自行配置的语言模型接口（用于调音助手的参数换算）；
  • 用户自行搭建的推理服务器（用于音色转换，未配置时数据不出本机）；
  • 公开的模型文件下载地址（只发生下载请求，不携带用户数据）。

以上第三方均由用户自己选择与配置，本软件不代理、不中转、不代为注册账号。这些服务对数据的处理适用其自身的隐私政策与服务条款。如用户选择的服务位于其所在国家或地区以外，相关数据会随该请求传输至境外——该传输由用户自行发起与决定。

七、用户对信息的控制

  • 联网开关：不填写任何 API Key 与服务器地址时，本软件不具备联网功能，也不会尝试连接；
  • 逐功能控制：每个联网功能都由用户在界面上单独触发，没有后台自动联网；
  • 麦克风控制：只在用户点击录音或启用分析时打开，可随时停止；
  • 本机运行选项：个人音色补音未配置服务器时默认在本机运行，不发送任何音频；
  • 撤回与清除：删除本机数据目录即可清除全部本地数据；删除设置中的 API Key 即撤回对相应服务的授权。

八、用户如何访问自己的信息

本软件的数据全部在本机，用户可以随时自行查看、复制与导出：

  • 录音、工程与导出文件：用文件管理器直接打开数据目录即可；
  • 设置项与 API Key：可在软件内「设置」中查看，或直接查看 %USERPROFILE%\.singmic\ 目录下的文件；
  • 由于不存在服务端存储，无需向开发者提出数据访问或导出申请。

九、插件支持包

VST3 插件功能由单独的「插件支持包」提供，它与主程序分开安装、分开运行，是一个独立程序。

  • 它只在本机读写音频数据与插件文件，不联网，不收集任何信息；
  • 主程序在未加载插件时不会启动它；
  • 用户不安装该支持包时，主程序其余功能不受影响；
  • 该支持包按 GPL-3.0 分发，其完整源代码随包提供。

十、模型文件与下载

语音识别与 AI 降噪使用在本机运行的模型。模型文件在用户确认后，从公开的下载地址取回并保存到本机数据目录。下载请求只包含文件本身，不携带用户数据、录音或任何标识信息。

软件本体的分发与更新由 Microsoft Store 提供；插件支持包与相关文档发布在本项目的公开仓库 github.com/IMXia-Chan/SingMic-Studio。

十一、儿童

本软件不面向儿童收集任何信息，也不存在账号体系与内容发布功能。

十二、法律合规与政策变更

本政策依照适用的法律法规与 Microsoft Store 政策编写。本软件新增功能或数据处理方式发生变化时，本政策将同步更新，并在本页面标注新的生效日期；涉及数据收集范围扩大的变更，会在软件更新说明中单独说明。
